# MVP 范围声明（Pinball Roguelike）

> 状态：原型阶段（核心循环已跑通，功能已超出最初 MVP 定义）/ 项目：2D 弹珠肉鸽（柏青哥风格）/ 引擎：Godot 4.7
>
> 最初定义见下方「原始 MVP」，当前实际范围见「现状」。二者不一致时以「现状」为准，原因记录在 `bible/99_decisions.md`。

## 现状（当前代码真实实现）

1. 一局 90 秒倒计时，起始库存 50 颗球；鼠标瞄准、按住左键蓄力、松开发射，每发消耗 1 颗库存球。
2. 球撞击图钉、穿过金环、落进底部洞口都会得分；球数只由"发射 -1 / 进洞 +N"改变。
3. 底部有 7 个洞口（+1~+5 球，分值 50~600）与 5 个普通区域（球消失、不回球也不扣分）。
4. HUD 实时显示关卡、剩余时间、球数、分数/目标分、连击与蓄力条，并提供"结算"按钮随时提前结束；按 Tab 查看累积属性与关卡跳转。
5. 结算判定：分数 ≥ 目标分（第 1 关 3000）即过关；分数达到目标分 ×2 会立刻提前过关。
6. 过关后从 10 种强化里随机三选一，进入更难的下一关（目标分 +800、时长 -5 s、图钉更密更快、金环更快）。
7. 失败则重试当前关，不回退已累积的强化。

## 原始 MVP（最初定义，已被超越）

1. 一局 90 秒倒计时，起始库存 50 颗球，目标 60 颗，达标即通关本局。
2. 按住左键连续发射弹珠，每发消耗 1 颗库存球；球撞击图钉与边界后随机改向。
3. 球落到底部：进奖励袋洞 +3 颗，落到普通区域不额外扣球，球消失。
4. HUD 实时显示剩余时间、库存球数、目标球数，并提供"结算"按钮随时提前结束。
5. 结算判定：球数 ≥ 60 显示"进入下一局"，否则显示"本局失败，重试"，重试重置为 90 秒 / 50 颗球。

## 做什么（原型阶段仍然成立）

1. 核心循环：瞄准 → 蓄力 → 发射 → 看球弹 → 看球进洞 → 看分数/球数变化 → 想再来一发。
2. 球数经济：球数是唯一资源，发射消耗、进洞回本，归零即出局。
3. 分数目标：分数是过关判定，与球数是两套数字。
4. 局间三选一强化：肉鸽标签的最小可行形态（10 选 3）。
5. 关卡递进：目标分递增、时长递减、台面变难。
6. 白盒表现：色块 + 占位 SVG，不加粒子不加音乐。

## 不做什么

1. 不做商店、Boss、随机房间、剧情事件、卡组构筑界面。
2. 不做正式美术与音效：全部保持白盒（色块 + 占位贴图），不加粒子、不加音乐。
3. 不做存档、成就、排行榜、多主角、多背景。
4. 不做移动端适配与打包导出，仅保证 PC 上 F5 可直接运行。
5. 不做平衡性深度调优与性能压测，数值先保证"能玩起来"而非"好玩到极致"。

## 验收标准

一个没接触过本项目的人，打开游戏后能在 30 秒内理解"瞄准蓄力—发射—看球落点—保住球数、刷够分数"这件事，并愿意再来一局。
