# 功能优先级表（Priority Backlog）

## 优先级定义

- **P0**：不做这个就不是这个游戏。核心循环的组成部分。
- **P1**：做了核心乐趣才完整。影响手感与可玩性的关键支撑。
- **P2**：做了能让游戏更耐玩。内容量与变化度。
- **P3**：做了更"高级"，但删掉不影响核心。打磨项。

## 功能清单

| 功能名 | 优先级 | 状态 | 一句话理由 |
| --- | --- | --- | --- |
| 发射器（蓄力发射） | P0 | 已完成 | 玩家唯一的主动输入，没有它就没有"下注"动作 |
| 球数经济（库存 ±） | P0 | 已完成 | 核心循环里"看球数有没有保住"的载体，是赌性的来源 |
| 奖励袋洞（回球 + 计分） | P0 | 已完成 | 唯一的正反馈出口，决定"还有机会翻一下"的手感 |
| 倒计时 | P0 | 已完成 | 给循环施加压力，没有时间限制就没有决策成本 |
| 结算判定（分数达标） | P0 | 已完成 | 一局的终点与胜负，形成完整闭环 |
| HUD（时间/球数/分数/连击/蓄力条） | P0 | 已完成 | 玩家看不见数字就无法决策 |
| 重试 / 再来一局 | P0 | 已完成 | 让循环能重复发生，否则玩一次就结束 |
| 物理反弹与图钉阵 | P0 | 已完成 | "看球弹"的随机性来源，乐趣的物理基础 |
| 三面边界墙 | P1 | 已完成 | 把球约束在屏幕内，否则球乱飞导致不可玩 |

| 关键数值 @export 暴露 | P1 | 已完成 | 不碰代码调手感的前提 |

| 局间三选一强化 | P2 | 已完成 | 肉鸽标签的核心，10 选 3 |
| 多关递进（目标分 +800 / 时长 -5s / 台面变难） | P2 | 已完成 | 提供长期目标与难度曲线 |

| 图钉耐久与击碎（变色 → 消失 → 清台奖励） | P2 | 已完成 | 增加打击感与"打光图钉"的额外目标 |
| 新台面元素（旋转挡板 / 传送门 / 加速带） | P2 | 已完成 | 内容量与变化度，依赖核心循环已成立（现已成立） |
| 更多局间强化（巨球 / 分裂 / 洞宽 / 进洞延时 / 图钉赏金） | P2 | 已完成 | 强化池从 10 种扩到 15 种 |
| 特殊球：满蓄力重球（一击击碎 + 双倍图钉分） | P2 | 已完成 | 给蓄力这个动作更多回报 |
| 正式美术与音效 | P3 | 未做 | 提升观感，不影响机制是否成立 |
| 存档 / 成就 / 排行榜 | P3 | 未做 | 元游戏系统，与核心循环无关 |
| 移动端适配与导出 | P3 | 未做 | 分发层面，玩法验证通过后再做 |
| 性能压测与大量球优化 | P3 | 未做 | 当前球量可控，非瓶颈 |

- 已完成（且已由无头冒烟测试验证）：发射器与蓄力、球数经济、袋洞回球、倒计时、结算判定、HUD、重试、图钉阵、边界墙与球清理、数值 @export、计分、金环、连击倍率、局间三选一强化、多关递进、关卡跳转。
- 已修复：点击 HUD 按钮误触发发射、洞口标签刷新丢失分数说明、金环静止时冷却不递减、击碎图钉时禁用碰撞体触发的物理报错。
- 2026-09-27 新增：图钉耐久与击碎、清台奖励、满蓄力重球、旋转挡板 / 传送门 / 加速带、强化池扩到 15 种；因击碎奖励大幅抬高产出，目标分由 3000 上调到 24000（每关 +5000）。
- 下一步候选（待定）：真机手感验证与数值微调、正式美术音效（P3）。
