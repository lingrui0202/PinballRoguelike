# 核心循环（Core Loop）

## 一句话描述

玩家用有限的球数下注：鼠标瞄准、按住蓄力、松开发射，靠图钉的随机改向与金环的精准穿过刷分数、靠底部洞口回球续命，在倒计时内把分数打到本关目标就能过关，过关后三选一强化进入更难的下一关。

## 循环图

```
瞄准 → 蓄力（按住） → 发射 → 看球弹（撞图钉/穿金环）
     → 看球进洞（回球 + 得分） → 看球数与分数有没有保住
     → 想再来一发 → (回到瞄准)
                              ↘ 分数达标 → 结算 → 三选一强化 → 下一关
```

## 两套数字

- **球数 = 资源**：发射 -1，进洞 +N。归零就不能再发射，场上球清空后自动结算。
- **分数 = 成绩**：撞钉 +10、穿环 +60、进洞 +洞口分值（都会乘连击倍率）。结算时够目标分才过关。

## 每个动词对应的功能

| 循环中的动词 | 对应功能 | 实现位置 | 优先级 |
| --- | --- | --- | --- |
| 瞄准 | 发射器指向鼠标，限制在朝上的扇形内；蓄力越满抖动越小 | `Launcher._aim_direction()` | P0 |
| 蓄力 | 按住左键蓄力，HUD 底部显示蓄力条；鼠标停在 UI 上不响应 | `Launcher._input()` | P0 |
| 发射 | 松开左键射出一颗球，库存 -1，球由 `BallTemplate` 复制而来 | `Launcher._fire_one()` | P0 |
| 看球弹 | 物理反弹 + 图钉阵碰撞（图钉每局随机缺失、部分左右移动） | `PegBoard` | P0 |
| 看穿环 | 球穿过金环得分并涨连击，球不消失 | `ring.gd` | P2 |
| 看进洞 | 底部 7 个洞口回球 + 计分；5 个普通区域球消失不扣分 | `bucket.gd` | P0 |
| 看球数变化 | 库存球数经济 + HUD 实时刷新 | `GameManager` / `HUD` | P0 |
| 看分数变化 | 分数 / 目标分 / 连击倍率 + HUD 实时刷新 | `GameManager` / `HUD` | P0 |
| 想再来一发 | 倒计时 + 结算面板 / 三选一强化 / 重试按钮 | `HUD` | P0 |
| （支撑项）边界与清理 | 三面墙 + 飞出屏幕清理 + 单球存活上限 | `Launcher._cleanup()` / `ball.gd` | P1 |
| （支撑项）手感可调 | 所有关键数值 `@export` 暴露 | 见 `bible/SPEC.md` | P1 |

## 循环的中断条件

| 条件 | 结果 |
| --- | --- |
| 倒计时归零 | 自动结算 |
| 球数为 0 且场上无球（满 3 秒） | 自动结算 |
| 分数达到目标分 × 2 | 立刻提前过关 |
| 玩家点"结算" | 手动结算 |
